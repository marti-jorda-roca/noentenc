# Security policy

## Supported versions

Report security issues affecting the latest release or `main`. Fixes are released in the current development version; older releases do not receive separate backports.

## Report a vulnerability

Use [GitHub's private vulnerability reporting form](https://github.com/marti-jorda-roca/noentenc/security/advisories/new). Do not disclose vulnerabilities or credentials in public issues or discussions.

Include the affected version, platform, model backend, reproduction steps, and the likely impact. Use a minimal example with synthetic data. If a downloaded model is involved, include its repository and revision without attaching private weights or data.

The maintainer will assess the report and coordinate a fix and disclosure with you. This project does not promise a response deadline.
